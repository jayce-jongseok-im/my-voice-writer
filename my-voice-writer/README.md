# my-voice-writer

내가 쓴 글 샘플을 한 번 학습시키면 같은 문체로 카드뉴스/에세이/블로그 글/SNS 캡션/이메일을 써주는 Claude Code 플러그인입니다.
**Pro·Max 구독으로 그대로 사용** 가능합니다 (별도 API 키 불필요).

## 기능

- 한국어 글쓰기에 특화. 사용자의 문장 길이·어미·줄바꿈·접속어·비유의 결을 그대로 따라갑니다.
- 4가지 출력 형식: 카드뉴스 / 에세이·블로그 / SNS 캡션 / 이메일·편지
- 3가지 입력 모드: 키워드+핵심문장 / 주제 한 줄 / 개요 펼치기
- 프로필은 `${CLAUDE_PLUGIN_DATA}` 에 안전하게 저장되어 재설치 후에도 유지됩니다.

## 사용

설치 후, Claude Code에서 다음 중 아무거나 하시면 됩니다.

**자연어**:
> 내 문체로 카드뉴스 7장 만들어줘. 키워드는 어버이날, 첫 만남, 작은 발. 마지막 카드에 "그렇게 우리는 가족이 되었습니다." 가 들어갔으면 좋겠어.

**슬래시 커맨드**:
```
/my-voice-writer:write  카드뉴스 7장, 어버이날 주제로
/my-voice-writer:profile show
/my-voice-writer:profile set
/my-voice-writer:profile clear
```

처음 사용할 때는 본인 글 샘플을 한 번 저장하라고 안내해드립니다 (2~4편, 합쳐서 800자 이상 권장).
