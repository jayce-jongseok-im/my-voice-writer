# My Voice Writer — 사용자 문체 보존 글쓰기 스킬

이 스킬은 사용자가 미리 저장해둔 본인 글 샘플을 읽어, 그 문체 그대로 새로운 글을 작성합니다. 카드뉴스, 에세이/블로그, SNS 캡션, 이메일·편지 네 가지 형식을 지원합니다.

---

## 데이터 위치

사용자 프로필은 다음 경로에 저장됩니다:

```
${CLAUDE_PLUGIN_DATA}/profile.md      # 본인 글 샘플 (필수)
${CLAUDE_PLUGIN_DATA}/style-notes.md  # 스타일 메모 (선택)
```

`${CLAUDE_PLUGIN_DATA}` 는 Claude Code가 자동으로 제공하는 플러그인 전용 디렉터리입니다. 이 위치는 플러그인 재설치 후에도 보존되며 다른 플러그인과 격리됩니다.

---

## 동작 흐름

스킬이 트리거되면 다음 순서로 진행하세요.

### 1단계: 프로필 점검

먼저 `${CLAUDE_PLUGIN_DATA}/profile.md` 파일이 존재하는지 확인합니다 (Read 도구 또는 bash로). 

- 파일이 없거나 내용이 100자 미만이면 → **2단계: 프로필 설정**으로 이동
- 파일이 있고 충분한 내용이 있으면 → **3단계: 글쓰기**로 바로 이동

### 2단계: 프로필 설정 (최초 1회)

사용자에게 한국어로 다음과 같이 안내합니다:

> 처음 사용하시는 거네요. 같은 문체로 글을 써드리려면 본인이 쓰신 글 2~4편을 먼저 학습해야 해요.
> 800자 이상 분량으로, 가능하면 다양한 톤의 글을 함께 주세요.
> 글과 글 사이는 빈 줄이나 `---` 로 구분해주시면 됩니다.
>
> 아래에 글 샘플을 붙여넣어 주세요.

사용자가 샘플을 제공하면:
1. `${CLAUDE_PLUGIN_DATA}` 디렉터리를 생성합니다 (`mkdir -p`).
2. 샘플 텍스트를 `${CLAUDE_PLUGIN_DATA}/profile.md` 에 저장합니다 (Write 도구).
3. 선택적으로 스타일 메모를 묻고, 답하면 `${CLAUDE_PLUGIN_DATA}/style-notes.md` 에 저장합니다.
4. 저장 후 "프로필 저장 완료. 이제 글 만들기를 진행할게요."라고 알리고 3단계로 이동합니다.

### 3단계: 글쓰기 입력 받기

사용자가 무엇을 쓸지 이미 명시했다면 그대로 진행합니다. 명시하지 않았다면 한국어로 다음을 묻습니다:

- **형식**: 카드뉴스 / 에세이·블로그 / SNS 캡션 / 이메일·편지 중 하나
- **카드뉴스인 경우 장면 수**: 5 / 7 / 9 / 10
- **길이**: 짧게 / 보통 / 길게 (카드뉴스는 해당 없음)
- **입력 방식 중 하나**:
  - 키워드 + 핵심 문장 (예: "어버이날, 처음 만난 날 / 그렇게 우리는 가족이 되었습니다.")
  - 주제 한 줄 (예: "처음 아이를 안았던 날의 마음")
  - 개요 펼치기 (불릿 형태로 도입–본론–마무리)
- **추가 메모** (선택): 톤, 강조하고 싶은 부분, 피하고 싶은 표현

가능하면 한 번의 응답 안에서 위 항목을 묶어 묻고, 사용자가 짧게 답할 수 있게 하세요.

### 4단계: 글 생성

`${CLAUDE_PLUGIN_DATA}/profile.md` 의 내용을 읽고, 그 문체를 정확히 모방해 글을 씁니다. 다음 규칙을 반드시 지키세요:

#### 문체 모방 원칙

1. **문장 길이와 리듬**을 샘플에서 그대로 가져옵니다. 샘플이 짧은 문장 위주면 짧게, 긴 문장 위주면 길게.
2. **어미** (`~다`, `~요`, `~습니다`)와 **존비어 수준**을 샘플과 동일하게 유지합니다.
3. **줄바꿈 습관**을 보존합니다. 샘플이 한 문장씩 줄바꿈하면 똑같이, 문단으로 묶으면 문단으로.
4. **자주 쓰는 접속어/부사**가 보이면 같은 빈도로 사용합니다. 보이지 않는 표현은 끌어들이지 않습니다.
5. **비유의 결**(자연/계절/일상/기억 등)이 샘플에 있으면 같은 영역에서 가져옵니다.
6. **이모지/이모티콘**은 샘플에 있을 때만, 같은 빈도로만 씁니다.
7. **샘플에 없는 어투/어휘 패턴**(예: 영어 차용어, 신조어, 특정 매체식 표현)을 새로 끌어들이지 마세요.

#### 형식별 출력 규칙

**카드뉴스** (`cardnews`)
- 사용자가 정한 장면 수만큼 카드를 만듭니다.
- 각 카드는 1–3줄의 짧은 문장으로 구성, 호흡을 천천히 가져갑니다.
- 출력 형식은 정확히 다음과 같이:
  ```
  카드 1) 본문...

  카드 2) 본문...
  ```
- 카드 사이는 빈 줄 한 줄. 머리말/꼬리말 없음.

**에세이/블로그** (`essay`)
- 한 편의 자연스러운 글로 작성. 제목은 붙이지 않습니다.
- 길이 기준:
  - 짧게: 200–350자
  - 보통: 500–800자
  - 길게: 1000–1500자
- 문단을 적절히 나누되, 사용자 샘플의 문단 패턴을 따릅니다.

**SNS 캡션** (`sns`)
- 인스타그램/스레드에 그대로 올릴 수 있는 톤.
- 마지막에 어울리는 해시태그 3–5개 추가. 단, 샘플에 해시태그 사용 흔적이 없다면 생략.

**이메일/편지** (`email`)
- 받는 사람에게 직접 말 거는 톤. 인사–본문–맺음 구조.
- 보내는 이/받는 이 표시는 빼고 본문만.

#### 출력시 주의

- **본문만 출력**합니다. "다음과 같이 작성해보았습니다" 같은 머리말, "참고가 되셨길 바랍니다" 같은 꼬리말, 코드 블록 감싸기 모두 금지.
- 사용자가 "다시 만들어줘"라고 하면 같은 입력으로 다른 버전을 시도합니다.
- 사실관계가 필요한 글(역사·시사·통계)은 모르는 정보를 만들어내지 말고, 사용자가 준 입력 안에서만 씁니다.

---

## 도움말 응답

사용자가 사용법을 묻거나 처음 써보는 분위기라면, 다음 핵심을 짧게 안내합니다:

- "내 문체로 카드뉴스 7장 만들어줘 — 어버이날, 첫 만남, 작은 발 / 그렇게 가족이 되었습니다." 이렇게 쓰면 됩니다.
- 형식·길이·장면 수를 말씀하시지 않으면 제가 한 번 더 여쭤봐요.
- 프로필을 새로 갱신하고 싶으면 `/my-voice-writer:profile` 슬래시 커맨드로 다시 설정할 수 있어요.

---

## 프로필 갱신 / 초기화 요청 처리

사용자가 "프로필 다시 저장할래", "샘플 바꿀래", "스타일 메모 추가" 같은 요청을 하면, 2단계의 프로필 설정 흐름을 다시 실행해 기존 파일을 덮어씁니다. 초기화는 `${CLAUDE_PLUGIN_DATA}/profile.md`와 `style-notes.md`를 삭제합니다.
